# citynight

도시의 밤, 옥상을 건너며 이어지는 사람들의 이야기. 2시간짜리 직선형 이야기 게임(작업 중, Godot 4.6).

실행: Mac `Run.command`, Windows `Run.cmd`(GODOT_EXE 지정), 또는 에디터에서 F5.
조작: WASD/방향키 이동, Space 점프·벽 점프, Shift 공중 대시(2회), K 유지 → 방향 → 놓기 튕기기, Tab 수치 패널.
검사: `python3 tests/run_tests.py --godot <Godot 경로>`.
작업 시작 전: `HANDOFF.md`.
