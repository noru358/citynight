# art

## 서울의 도시 분위기 (2026-10-14)

- 사용자 확정: 한국적 정체성은 '서울스러움'으로 구체화한다. 시티팝 감성과 서울 특유의 다양한 미관·배경·생활 공간을 함께 살린다. 고층 건물 옥상 점프만 반복하지 않는다.
- 인물·설정은 원점 재검토 중이다. 밤 친구·도깨비·사물 기원을 외형의 필수 조건으로 삼지 않는다. 서울의 밤과 시티팝 감성, 기존 아트 기준은 유지한다.
- [서울 공간 조사와 아트 제안](SEOUL_REFERENCE.md): 실제 장소 자료와 창작 제안을 구분했다. 공간 목록·구역 수·조명 변화안은 검토 후보이며 최종 맵이나 새 팔레트 확정이 아니다.
- 아래 640×360, 20px 타일, 34px 주인공 기준을 유지한다. 기존 팔레트/이미지는 이번 문서 작업에서 바꾸지 않았다.

## 기준 (2026-10-13 확정)

- 기준 해상도 640×360. 2·3·4·6배 정수 배율로 720p·1080p·1440p·4K. 16:10 화면은 위아래 띠를 하늘로 메운다.
- 타일 20px. 화면에 가로 32칸, 세로 18칸.
- 주인공 키 34px(타일 1.7칸). 히트박스는 그림보다 조금 작게(약 20×32).
- 공간감은 평소 시야가 아니라 연출로 낸다. 사연이 터지는 순간 카메라를 2배로 뺀다.
- 주인공 뒤 배경은 명도를 한 단계 눌러 둔다(시안 B에서 주인공이 밝은 창 앞에서 묻혔다).
- 시안: `baseline_mock.png`(640×360을 2배로 키운 것). 비교했던 다른 안은 프로젝트 공유 폴더 `art-baseline/`.

## 제작 방식

- 배경·건물: 이미지 도구로 생성 → 스크립트로 격자 맞추기 + 팔레트 강제 변환 → 검수.
- 주인공·인물: 기준 그림 한 장을 사용자가 손으로 확정. 동작 프레임은 그걸 바탕으로 만들고 사용자가 픽셀 보정. 팔레트로는 인물 일관성과 프레임 일관성이 안 잡힌다.
- 아직 정할 것: 빛 방향, 외곽선 유무, 디더링 허용 범위, 스프라이트당 색 수.
