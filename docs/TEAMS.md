# 팀과 할 일 (2026-10-13)

사람은 사용자 한 명, 나머지는 Claude·Codex·이미지 생성 도구다. "팀"은 결정과 산출물이 어디에 모이는지를 나누는 이름이다.

## 최신 공동 인계 (2026-10-14, 원점 재검토)

- 유지할 핵심: 서울의 밤, 시티팝 감성, 액션·성장 RPG.
- 인물·세계관·동료·전개를 원점에서 재검토한다. 밤 친구·내일 회피·긴 밤의 공모·경계 확장은 현재 필수 전제가 아니다. `docs/story/README.md`를 현재 안건으로 읽는다.
- 기존 설화 조사와 긴 밤 연출 문서는 이전 기획 참고 자료다. 서울 공간 조사는 계속 활용할 수 있다.
- 성장 방식·전투 체계·분량·진행 구성은 새 방향과 함께 검토한다. 기존 프로토타입·아트 기준을 임의로 바꾸거나 구현부터 시작하지 않는다.

## 프로듀서 — 사용자
- 방향 최종 결정, 플레이·장면 판정. 판정은 "찡한가, 끝까지 가고 싶은가".

## 스토리팀 — 주인: 사용자 / 보조: Claude
- 스토리, 주인공 컨셉, 세계관, 등장인물, 사건(퀘스트).
- 뼈와 디테일은 사용자. Claude는 구조 정리, 장 나누기, 일관성 검사, 사용자 문학 규칙 검사(감정 직접 명명 금지, 배경 설명 대신 행동, 기능적 도시 사물, 첫 사물을 변형된 형태로 되돌리며 마무리). 줄거리 후보를 여러 개 뽑아 내밀지 않는다.
- 산출물: `docs/story/`.

## 연출·레벨팀 — 주인: Claude / 구현: Codex / 판정: 사용자 (새로 추가)
- 스토리 비트를 맵·카메라·타이밍·음악 큐·세계의 반응으로 바꾼다. 우선순위 2번(연출)이 비어 있어서 따로 뺐다.
- 맵 텍스트(`maps/`), 장 데이터(`data/chapters/`), 장면 설계서(`docs/plan/`).

## 아트팀 — 방향: 사용자 / 설계·검수: Claude / 생성: Codex·이미지 도구 / 손보정: 사용자
- 도트 + 시티팝 감성. 팔레트, 해상도, 타일·캐릭터 크기, 에셋 제작.
- 도트는 사용자가 픽셀을 직접 고칠 수 있어서 "말로 고쳐 달라고 해야 하는" 문제를 줄인다.
- 먼저 정할 것: 기준 해상도와 주인공 키(픽셀), 팔레트 한 장.
- 산출물: `docs/art/`, `assets/`.

## 음악팀 — 보류
- 지금은 손대지 않는다. 다만 연출 시험(클라이맥스 30초)에는 곡이 필요하므로, 그때 내부 시험용 임시곡을 쓰거나 시험곡 하나만 만든다. 출시 곡은 직접 제작(실제 시티팝 곡은 저작권 때문에 못 씀).

## 개발 기획팀 — Claude(설계·검수·문서) + Codex(구현)
- 게임플레이 디자인: 액션과 성장 RPG가 핵심 요구다. 전투와 성장의 구체 방식·규모를 여기서 검토한다. 현재 구현 여부와 기획 요구를 구별한다.
- 입력·무기·전투 빈도·성장 체계는 미정이다. 액션 성장 RPG를 기존 줄거리에 전투만 추가하는 식으로 해석하지 않는다. 인물의 내면을 괴물로 만들고 처치로 치유하는 일대일 비유에 대한 이전 거부를 자동으로 해제하지 않는다.
- 빌드·검사: `tests/run_tests.py`, CI, 윈도우 실행 묶음.
