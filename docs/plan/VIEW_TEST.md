# 전투 뷰 비교 시험 (2026-10-14)

같은 전투를 옆 화면과 탑뷰 두 벌로 붙인 회색 상자 방. 뷰를 문서가 아니라 손으로 고르기 위한 것이다. 그림·괴물 모양·수치는 전부 임시.

## 실행

게임을 켜고 위 버튼 "전투 시험". 방 안에서 "뷰 바꾸기"(또는 V)로 옆 화면과 탑뷰를 오간다. R은 처음부터, "옥상으로"는 원래 장으로.

조작: 베기 J 또는 좌클릭, 사격 L 또는 우클릭. 마우스를 움직이면 2초 동안 마우스 쪽으로 조준하고, 아니면 방향키 쪽, 아니면 바라보는 쪽. 옆 화면은 지금 이동 그대로(점프, 벽 점프, 대시 1회, 튕기기 K). 탑뷰는 8방향 이동과 대시(Space 또는 Shift), 점프 없음.

## 같은 규칙

체력 6. 탄 3칸, 사격은 한 칸 쓰고 세다(3 피해, 멀리 밀침). 탄은 베기가 맞아야만 찬다(맞힌 괴물 하나당 0.34칸, 세 번에 한 발). 베기는 적 탄도 쳐낸다. 대시 중엔 안 맞는다.

괴물 둘. 덩어리(보라)는 다가와 번쩍이며 준비했다가 돌진한다. 돌진만 아프고, 준비 중에 베면 끊긴다. 간판 머리(청록)는 거리를 두고 빨간 조준선을 그은 뒤 느린 탄 한 발. 파도 넷(3 / 3+1 / 4+2 / 5+3).

옆 화면만 있는 것: 공중에서 아래+베기가 맞으면 튕겨 오른다(대시 다시 참). 괴물도 튕기기(K) 대상이다(1 피해, 탄 충전).

수치는 `arena/combat_tuning.json`. 판이 끝날 때마다 기록이 `user://citynight_log.jsonl`에 `arena` 항목으로 남는다.

## 볼 것

어느 쪽에서 더 계속 싸우고 싶은가. 붙을 이유와 떨어질 이유가 느껴지는가(칼질이 충전 노동인가). 괴물의 준비 동작과 조준선이 잘 읽히는가. 서울 밤 분위기가 어느 쪽에서 더 사는가.

## 확인한 것 / 못 한 것

확인: `tests/ArenaProbe`(단순 봇)가 두 뷰 모두 네 파도를 끝까지 깬다. 캡처로 화면 구도 확인. 기존 검사(DataSuite, RouteProbe, PracticeProbe) 통과.
못 한 것: 사람 손맛. 봇 통과는 재미 판정이 아니다. 탑뷰는 거리 한가운데 서면 하늘이 화면 밖으로 나간다(가게 정면 줄만 보임). 탑뷰 괴물은 소품 뒤에서 잠깐 옆으로 비켜 도는 정도의 길찾기만 있다.
